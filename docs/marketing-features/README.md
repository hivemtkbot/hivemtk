# HiveMtk 核心功能总览

> **定位**: 单商户本地部署的核心功能清单
> **架构**: 单体应用（user-server + user-web），PostgreSQL + Redis + llama.cpp

---

## 一、核心模块

### 1.1 AI 销冠引擎
- **对话记忆**: 短期上下文 + 长期记忆 + RAG 检索
- **意图识别**: 12 类意图分类（问候、咨询、购买、投诉等）
- **SOP 执行**: DAG 流程编排，支持分支与循环
- **LLM 路由**: 多模型自动降级（本地 llama.cpp → 云端 LLM）
- **异议处理**: 基于历史数据的智能应对策略
- **触达 Pipeline**: 9 步执行框架（感知→决策→行动）

### 1.2 知识库与 RAG
- **知识库管理**: 文档导入、分段、向量化
- **向量检索**: pgvector 相似度搜索
- **智能客服**: 基于 RAG 的自动问答
- **话术库**: 预定义话术模板管理

### 1.3 渠道接入
- **微信/企微**: 公众号、小程序、企业微信
- **抖音/快手/小红书**: 多平台卡片消息
- **邮件**: SMTP 发送、追踪、退订管理
- **短信**: 阿里云/腾讯云/华为云 SMS
- **Web Widget**: 嵌入式客服聊天窗口

### 1.4 客户管理
- **客户 360**: 统一客户视图
- **线索管理**: 线索收集、分配、跟进
- **标签分层**: RFM 模型、行为标签
- **客服会话**: 会话记录、快捷回复、AI 建议

### 1.5 营销自动化
- **流程编排**: 可视化营销流程设计
- **A/B 测试**: 方案对比
- **流失预警**: 基于行为的流失预测
- **数据大屏**: 实时数据展示

### 1.6 系统管理
- **用户管理**: 账号、角色、权限
- **系统配置**: 全局参数设置
- **备份恢复**: 数据库自动备份
- **操作日志**: 审计追踪

## 三、技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| 后端 | Go 1.22+ | Gin Web Framework |
| 前端 | Vue 3 + Vite | 用户界面 |
| 数据库 | PostgreSQL 15+ | 主存储 + pgvector |
| 缓存 | Redis 7 | 会话 + 缓存 |
| LLM | llama.cpp | 本地推理 |
| ORM | GORM | 数据访问 |
