## 四、不符合本项目需求（前提不成立 / 适用性错误）

1. **国学算法测试用例（H3 / 4.4 / 8.4）——整条不适用**
   全仓检索 `国学|八字|紫微|bazi|算命|占卜|风水` 仅 1 处命中，且为误匹配（`signal_collector.go` 中 `computeEntityComp` 实体比较注释，项目**无任何国学算法模块**）。报告引用的"项目记忆要求每种国学算法 ≥100 组用例"与代码现实不符——该要求本身可能源于过期记忆。应**整条删除**。
2. **5.2 平台端 JWT"高危"——适用前提错误**
   本项目平台端即私有部署管理后台，JWT 鉴权是合理设计，非缺陷。原报告把"所有端无认证"的误读套用到平台端，结论不成立。
3. **L4 建议"补充 GitHub Actions"——未贴合协作现实**
   项目主远端为 Gitee（分支 master，远端 gitee），且已存在 Gitee 协同。单推 GitHub Actions 偏离实际流程，应改为"GitHub Actions + Gitee Go 双管线"或以 Gitee CI 为主。
4. **2.4/2.5 等"注册/定价已移除"核查口径偏严**
   基于旧的"开源硬约束"快照。最新术语规范已允许"公开下载/部署"等自托管表述，部分"违规"判定需与 `website/TERMINOLOGY.md` 重新对齐。
