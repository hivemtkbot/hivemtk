# 工具可见性与配置方案设计

## 1. 背景

当前系统有 40 个 AI Agent 工具，但用户无法在前端界面：
- 查看有哪些工具可用
- 配置三方账号信息（如短信、邮件、Telegram 等）
- 选择是否开启/禁用特定工具

同时，产品官网（landing page）需要展示产品的 AI 能力，让潜在客户了解产品价值。

## 2. 设计目标

### 2.1 user-web 后台管理界面

| 功能 | 描述 |
|------|------|
| 工具总览 | 展示所有工具，按分类组织 |
| 工具详情 | 查看工具描述、参数、使用示例 |
| 账号配置 | 配置三方服务账号（短信、邮件、Telegram 等） |
| 启用/禁用 | 按工具或按分类控制是否启用 |
| 状态监控 | 查看工具调用统计、成功率、错误率 |

### 2.2 website 产品官网

| 功能 | 描述 |
|------|------|
| 能力展示 | 展示 AI Agent 的 41 个工具能力 |
| 场景示例 | 按业务场景展示工具组合 |
| 技术亮点 | 展示 ReAct 循环、工具链等技术优势 |
| 竞品对比 | 与市面其他方案的差异化对比 |

### 3.3 API 设计

```yaml
# 工具管理相关 API
GET    /api/agent/tools                    # 获取工具列表
GET    /api/agent/tools/:name              # 获取工具详情
PUT    /api/agent/tools/:name/status       # 更新工具启用状态
GET    /api/agent/tools/providers          # 获取 Provider 列表
GET    /api/agent/tools/stats              # 获取工具统计

# 账号配置相关 API
GET    /api/agent/accounts                 # 获取账号配置列表
POST   /api/agent/accounts                 # 创建账号配置
PUT    /api/agent/accounts/:id             # 更新账号配置
DELETE /api/agent/accounts/:id             # 删除账号配置
POST   /api/agent/accounts/:id/test        # 测试账号连接
```
