## 二、执行约束

1. **每完成一个任务,立即 git commit**(遵循 project_memory Git 纪律)
2. **每个任务前**:`bash scripts/check-architecture.sh` 记录基线
3. **每个任务后**:同命令验证;仅本任务相关违规数下降,其他不变
4. **冲突回避**:任一任务若发现与其他在跑任务有冲突,立即 `blocked` 标记 + 自动跳过到下一项
5. **不修改 ctx 透传**:严禁在 `repository/*.go` 中"顺便把 ctx 也加进去"——这是另一专项的工作
