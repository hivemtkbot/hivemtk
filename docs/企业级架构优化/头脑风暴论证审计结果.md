## 四、头脑风暴论证：改进项详解

### 4.1 A1 — middleware/auth.go 死代码引用外部授权

**问题**：
- 文件 [auth.go](file:///Users/xiaofang/Documents/www/go/hivemtk/hivemtk/user-server/internal/middleware/auth.go#L47) 第 47 行 `const authCheckURL = "https://auth.xapptool.cn"` 引用外部授权服务
- `AuthMiddleware()` 函数 [L85-L122](file:///Users/xiaofang/Documents/www/go/hivemtk/hivemtk/user-server/internal/middleware/auth.go#L85-L122) 调用 `checkAuthorizationWithTimeout` 向 `auth.xapptool.cn` 发送 POST 请求验证 API Key
- 项目硬约束明确：「开源、无认证」

**论证三问**：

| 问 | 答 |
| --- | --- |
| 修复 vs 保留？ | 必须修复。死代码 + 外部授权 URL 违反「开源、无认证」「数据封死在域内」两条硬约束 |
| 立即修复 vs 延后？ | 立即修复。grep 确认 `AuthMiddleware()` 未在任何 router 中注册，仅在 `api_key_test.go` 中被测试，是死代码 |
| 此方案 vs 备选？ | 删除整个 auth.go + api_key_test.go。备选「保留文件但移除外部 URL」会留下无用代码，反而增加维护成本 |

**修复方案**：删除 `user-server/internal/middleware/auth.go` + `user-server/internal/middleware/api_key_test.go`
