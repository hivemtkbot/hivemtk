==================================================================================================
【 核心智能体引擎：用户输入处理生命周期 (单次推理闭环) 】
==================================================================================================
   [ 外部客户输入 (Web/TG/WA) ] 
         │
         ▼
   [ 1. 情绪感知模块 (Sentiment Sensor) ] ──> 提取显性词+隐性语义 -> 拆解为 [平静/焦虑/愤怒/赞赏]
         │
         ▼
   [ 2. 意图识别模块 (Intent Router) ] ────> 划分核心业务路由 -> 拆解为 [闲聊/询价/查单/投诉退款]
         │
         ▼
   [ 3. 6维拟人度自适应打分 (6-D Alignment) ] ──> 内存多轨微调打分 (1-5分)：
         │                                      ├── 同理心评分 (针对用户焦虑/愤怒指数)
         │                                      ├── 热情度评分 (针对询价/赞赏指数)
         │                                      └── 专业度评分 (针对知识库检索置信度)
         │
         ▼
   [ 4. 危机感安全门禁 (Crisis Gatekeeper) ] ─> 判定【危机感评分】是否 >= 4分，或检测到“退款/骗子/起诉”等词
         │
         ├─── ( 是：满足熔断条件 ) ──────> [ 5. 触发转人工门禁 (Human Escalation) ]
         │                                        └── 下发 Redis 永久会话锁定锁 / 坐席后台发出“叮咚”报警
         │
         └─── ( 否：满足托管条件 ) ──────> [ 6. 任务规划器 (Planner) ] -> 执行后续工具调用或拟人化文本输出
=================================================================================================
