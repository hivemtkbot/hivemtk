# 功能模块全景图

> **关联文档**: `功能模块全景对齐清单.md`、`认知决策大脑层.md`、`渠道接入消息中台.md`  
> **范围**: 本图描述 **Agent 决策闭环**（渠道接入 → 智能体引擎 → 工具/记忆/本地算力），**不是**产品全功能目录。  
> 营销自动化 / 团队系统 / 卡片平台 / 支付备份等业务运营模块见 `docs/CROSS_COMPARISON_REPORT.md` 与 `docs/marketing-features/`。

```
==================================================================================================
【 1. 渠道接入与会话中台 (可见层 Web 服务集群) 】
==================================================================================================
   ├── [ 网页客服模块 ] ────> 一行 <script> 标签引入 / 悬浮聊天窗 UI / WebSocket 长连接
   ├── [ TG 渠道模块 ] ─────> Bot Token 校验 / Webhook 注册 / 过滤群组垃圾广告与高频刷屏
   ├── [ WhatsApp 模块 ] ──> Meta 开发者密钥配置 / 官方消息模板同步 / 按钮卡片原生 API 下发
   ├── [ 闲鱼 / 平台机器人 ] > 浏览器通道 WS / 平台账号绑定（见 channelbot + browser 适配）
   ├── [ 企微 / 飞书等 ] ───> 企业 IM 账号接入与健康检查（业务侧扩展渠道）
   └── [ 统一消息入站 Ingress ]
         · MessageEvent 统一格式
         · 人工接管锁 (hivemtk:lock:human:{session})
         · AI 串行防抖锁 + pending 队列
         · 与「坐席侧 InboxService / MessageHub」职责分离
                                        │
                                        ▼ (异步投递 / 触发 AgentRuntime)
==================================================================================================
【 2. 核心智能体引擎 (底层 Agent 决策守护进程) 】
==================================================================================================
   推理闭环 InferenceCycle（顺序固定）:
   Perception → Alignment(6维) → Gatekeeper(危机) → Planner

   ├── [ 动态织布上下文 Weave ] ─> OpenAI messages 拼装：
   │     资产包 System/Few-Shot + 本地 RAG 切片 + 会话历史 + 当前用户问句
   ├── [ 感知与意图识别 ] ──────> 意图(询价/查单/投诉/…) + 情绪(平静/焦虑/愤怒/…)
   ├── [ 拟人度 6 维门禁 ] ─────> 同理心 / 热情 / 专业 / 耐心 / 清晰 / 礼貌（1–5 分）
   ├── [ 门禁自动熔断器 ] ──────> 危机等级 High 或高危词 → 切断 AI 自动回复
   │     · 判定: DefaultCrisisDetector
   │     · 执行: HumanEscalationManager（Redis 永久会话锁 + 坐席通知）
   └── [ 任务规划器 Planner ] ─> Thought-Action / 工具链规划 / FAQ 直出 / ReAct 适配
                                        │
                                        ▼ (调度工具注册表)
==================================================================================================
【 3. 工具注册表 (智能体手脚组件) 】           【 4. 分层记忆系统 (数据与状态中心) 】
==================================================================================================
   ├── [ customer.* 客户模块 ]                    ├── [ L1 短期活跃记忆 ] (Redis / 会话)
   │     └── 画像 / 标签 / 分群 / OneID 合并       │     └── 近期明文历史（Weave 截断注入）
   ├── [ reach.* 营销触达 ]                       ├── [ L2 长期语义记忆 ] (PGvector)
   │     └── 多渠道触达 / 回访私信                 │     └── 结构化标签与知识向量
   ├── [ rag.* / knowledge.* 知识库 ]              ├── [ L3 业务 SOP 状态 ] (Redis/PG)
   │     └── 向量检索 / 文档入库 / 反馈            │     └── 流程进度与节点执行器
   ├── [ pm.* 私信卡片控制 ]                      └── [ L4 业务实体快照 ] (PostgreSQL)
   │     └── 多媒体按钮 / 表单卡片                      └── 订单 / 线索 / 工单 / RFM
   ├── [ business.* 业务操作 ]
   └── [ ToolRouter 统一路由 ] ──> 限流 / 熔断 / 审计 / 成本 / 装饰器链
                                        │
                                        ▼ (驱动算力基础)
==================================================================================================
【 5. 本地 AI 算力底座 (基础设施集群) 】
==================================================================================================
   ├── [ 本地推理引擎 llama-server :8207 ] ──> 宿主机 llama.cpp（OpenAI 兼容 /v1/chat/completions）
   │     · 可并行：外部厂商 API（dispatcher 双模 + 熔断 failover）
   ├── [ 向量化服务器 llama-server :8208 ] > 宿主机 llama.cpp Embedding（OpenAI 兼容 /v1/embeddings）
   │     · 客户端: internal/aiagent/embedding/
   └── [ 语义重排引擎 llama-server :8209 ] ──> 宿主机 llama.cpp Rerank（/v1/rerank）
         · 客户端: internal/aiagent/rag/retrieval/rerank*.go

   约束: Embedding 必须本地；禁止默认静默降级为伪向量；数据不出域优先。
=================================================================================================
```

## 与代码主路径对照（速查）

| 全景模块 | 主实现 |
|---|---|
| Ingress 入站 | `user-server/internal/service/inbox_ingress.go` |
| Weave 织布 | `user-server/internal/service/asset_bundle.go` → `Weave` |
| 6 维对齐 | `.../agent/runtime/alignment_stage.go` |
| 危机门禁 | `.../agent/runtime/gatekeeper_stage.go` |
| 转人工执行 | `.../service/human_escalation.go` → `HumanEscalationManager` |
| Planner | `.../agent/runtime/planner_stage.go` |
| 工具路由 | `.../agent/tooluse/tool_router.go` → `ToolRouter.Route` |
| 推理栈部署 | 宿主机 llama.cpp 进程（`scripts/inference-host/`）：llama-server :8207/:8208/:8209 |
