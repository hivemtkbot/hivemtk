【 2. 核心智能体引擎 (底层不可见 Agent 决策守护进程) 】
==================================================================================================
   ├── [ 动态织布上下文 ] ──> 运行期内存组装：System主提示词 + 实时RAG文档 + 激活工具链 + L1历史
   ├── [ 感知与意图识别 ] ──> 实时判定客户意图(询价/查单/投诉) / 细分情感状态(平静/焦虑/愤怒)
   ├── [ 拟人度 6 维门禁 ] ─> 实时自适应打分(同理心/热情度/口语化等) / 监控“退款/诈骗”等高危词
   ├── [ 门禁自动熔断器 ] ──> 当危机感评分 >= 4 分时，立即切断 AI 自动回复，强行激活人工接管
   └── [ 任务规划器(Planner) ] > 采用 Thought-Action 范式引导本地模型，自动规划外部工具链调用顺序
                                        │
                                        ▼ (调度工具注册表)

【 5. 本地 AI 算力底座 (基础设施集群) 】
==================================================================================================
