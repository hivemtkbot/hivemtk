## Provider：aftersale

### `aftersale.create`

**功能**：为客户发起售后（退款/退货退款/换货）。这是客服系统对订单唯一允许写入的操作：创建售后请求并回写电商，由电商执行落地，本系统只记录售后单与状态。下单、支付、履约不属于客服职责。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `amount` | integer | — | 售后金额（分），退款/退货时建议提供 |
| `customer_name` | string | — | 客户姓名（可选） |
| `customer_phone` | string | — | 客户手机号（用于回写电商与跟踪） |
| `order_id` | string | ✅ | 关联订单号（必填） |
| `platform` | string | — | 电商平台标识（如 taobao/jd） |
| `reason` | string | — | 售后原因（可选） |
| `type` | string | — | 售后类型：refund（仅退款）/ return（退货退款）/ exchange（换货） |

**实测响应**：
- 状态：`success=true`（业务跑通）
- 响应示例：`{"after_sale_id": 4, "message": "售后请求已发起，等待电商处理（状态将通过回写刷新）", "order_id": "TEST_ORDER_001", "status": "pending", "type": "refund"}`

**功能**：创建客户跟进任务（提醒）。联动客户旅程阶段自动推进 + 销售仪表盘。用于智能体识别意向后自动排程跟进、销售手动安排回访。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `auto_handle` | boolean | — | 是否由 AI 自动处理（默认 false） |
| `channel` | string | — | 触达渠道（可选，如 wecom/sms/email） |
| `customer_id` | string | ✅ | 客户 ID（必填） |
| `description` | string | — | 跟进描述（可选） |

| `priority` | integer | — | 优先级：0=低 / 1=普通 / 2=高 / 3=紧急 |
| `sop_name` | string | — | 关联 SOP 名称（可选） |
| `title` | string | — | 跟进标题（可选，默认使用 type） |

### `rag.search`

**功能**：在指定知识库（RAG 产品）中检索与查询相关的文档分段。返回 top_k 个最相关的分段（含 score、content、document_id）。用于客服答疑、销售话术推荐、知识查询等场景。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `metadata_filters` | object | — | 附加字段过滤（可选）。例如 {"customer_id":"123","order_id":"A01"}，将检索收敛到特定业务上下文（某客户的订单知识等）。 |
| `product_id` | string | ✅ | RAG 产品 ID（知识库 UUID） |
| `query` | string | ✅ | 检索查询文本（用户问题或关键词） |
| `session_id` | string | — | 会话 ID（可选，用于关联检索日志与反馈） |
| `threshold` | number | — | 相似度阈值（0-1，默认 0.3）。低于此分数的分段将被过滤。 |
| `top_k` | integer | — | 返回分段数量上限（默认 5，最大 20） |

**实测响应**：
- 状态：`success=true`（业务跑通）
- 响应示例：`{"avg_score": 0, "chunks": [], "latency_ms": 52, "max_score": 0, "min_score": 0, "query": "自动化测试查询", "threshold": 0.3, "top_k": 5, "total": 0}`
