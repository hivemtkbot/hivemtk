## 功能域 4 - 分层记忆系统

| 层级 | 介质 | 现状 | 代码路径 |
|---|---|---|---|
| L1 短期活跃记忆 | Redis List (最近 3 轮) | 已落地 | `internal/rag/retrieval/redis_cache.go` + `internal/aiagent/agent/runtime/types.go` (SalesRequest) |
| L2 长期语义记忆 | PGvector | 已落地 | `internal/vector/vector_model.go` + `internal/aiagent/knowledge/model/knowledge_merchant.go` |
| L3 业务 SOP 状态 | Redis Key | 已落地 | `internal/service/sop.go` + `internal/service/sop_loader.go` |
| L4 业务实体快照 | PostgreSQL | 已落地 | `internal/service/order.go` / `clue.go` / `user.go` |

**L1 限制**: 严格保留最近 3 轮明文历史对话，超出部分转 L2 长期记忆 (异步提炼)。
**L2 提炼任务**: `internal/aiagent/agent/runtime/publisher_knowledge.go` 异步触发向量化。
**L3 SOP 阶段**: `Start → Greet → Probe → Value → Objection → Closing → End`，可任意节点转人工。
**L4 业务实体**: 关联订单号 / 未完结投诉工单 / RFM 标签快照。

- ✅ 6 厂商 8 场景，限流备用 + 熔断降级
