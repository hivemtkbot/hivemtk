marketing-chat-widget Demo 多场景对比

本页面演示 6 种典型接入场景,所有 API 地址 / 渠道 ID 都用占位符({apiBaseUrl} {channelId} 等),方便快速替换。默认指向 {apiBaseUrl}。

占位符:
修改后点击对应场景卡片下的"激活此场景"按钮即可热切换(将销毁当前 widget,重新加载新配置)。

1. 基础接入 最简

一行 <script> 即可嵌入。AppKey/Channel 都省略,后端使用默认 channel(私域部署模式)。

<script src="{apiBaseUrl}/embed/marketing-chat-widget.iife.js"></script>

当前场景配置

apiBaseURL{apiBaseUrl} channelRefdefault(自动)

2. 多渠道 data-*

每个企业 / 网站用不同的 AppKey,自动路由到不同客服组。

<script
  src="{apiBaseUrl}/embed/marketing-chat-widget.iife.js"
  data-app-key="{channelId}"
  data-color="{primaryColor}"
  data-welcome="您好,这里是{channelId}专属客服"
  data-lang="zh-CN"
></script>

当前场景配置

appKey{channelId} color{primaryColor} welcome您好,这里是{channelId}专属客服

3. 跨域部署 跨域

企业官网与 user-server 不同域,需要显式指定 data-api-base-url。

<!-- 父页:https://www.example.com -->
<!-- 后端:https://chat.example.com -->
<script
  src="https://www.example.com/embed/marketing-chat-widget.iife.js"
  data-api-base-url="https://chat.example.com"
  data-app-key="{channelId}"
></script>

跨域关键参数

  • data-api-base-url = 真实后端 origin(必填,跨域场景)
  • 父端自动从 apiBaseURL + window.location.origin 推导 allowedOrigins 白名单
  • iframe 端用具体 origin 发送 postMessage,不用 '*'

4. CDN 部署 CDN

JS 静态资源走 CDN,API/WebSocket 走 user-server 域名(同跨域场景,但用 CDN 加速)。

<script
  src="https://cdn.example.com/embed/marketing-chat-widget.iife.js"
  data-api-base-url="https://chat.example.com"
  data-color="{primaryColor}"
></script>

构建产物

# embed-sdk/
npm run build
# 产物在 dist/marketing-chat-widget.iife.js + dist/marketing-chat-widget.esm.js
# 上传到 CDN: aws s3 sync dist/ s3://cdn.example.com/embed/

5. 编程式控制 API

通过 window.mcwInstance 主动控制 widget 开关,适合自定义按钮触发场景。

// 打开聊天窗
window.mcwInstance.open()

// 关闭聊天窗
window.mcwInstance.close()

// 完全销毁
window.mcwInstance.destroy()

// 监听事件(可选)
window.MarketingChatWidgetConfig = {
  apiBaseURL: '{apiBaseUrl}',
  color: '{primaryColor}',
  events: {
    onReady: (info) => console.log('widget ready', info),
    onOpen: () => console.log('chat opened'),
    onClose: () => console.log('chat closed'),
    onUnread: ({ count }) => console.log('unread =', count),
    onMessage: ({ type, payload }) => console.log('message', type, payload)
  }
}

6. 全局变量配置 JS

在引入 SDK 之前定义 window.MarketingChatWidgetConfig,适合无法修改 HTML(data-* 不便)的场景。

<script>
  window.MarketingChatWidgetConfig = {
    apiBaseURL: '{apiBaseUrl}',
    appKey: '{channelId}',
    color: '{primaryColor}',
    position: 'bottom-left',
    welcome: 'Hi, how can I help you?',
    lang: 'en-US',
    width: 400,
    height: 600,
    events: {
      onReady: function(info) { console.log('ready', info) }
    }
  }
</script>
<script src="{apiBaseUrl}/embed/marketing-chat-widget.iife.js"></script>
优先级:data-* 属性 > window.MarketingChatWidgetConfig > query 参数 > 内置默认值
